# Quiz de programação

Teste seus conhecimentos sobre a web.

## Executar

Abra o arquivo index.html em um navegador moderno. Não há dependências, instalação ou compilação. Para um endereço local estável, use um servidor de desenvolvimento, como o Live Server do VS Code.

## Conceitos

Arrays, objetos, eventos, pontuação e estado da interface.

## Roteiro de aula

1. Explore o resultado no navegador e identifique as regras.
2. Construa a estrutura semântica em index.html.
3. Estilize a interface em css/style.css e teste em tela pequena.
4. Implemente os eventos e a lógica em js/script.js.
5. Teste entradas, reinício e condições de fim quando aplicáveis.
6. Faça um commit a cada etapa concluída.

## Desafios

Adicionar perguntas; embaralhar alternativas; criar categorias.

## Teste manual

Teste o fluxo principal, navegação por teclado e tela de celular. Confira mensagens de erro e reinício, quando disponíveis. Nos projetos com armazenamento, recarregue a página e confira a persistência. O armazenamento pertence ao navegador e à origem utilizada; não compartilha dados entre dispositivos.

## Git

Para iniciar um repositório independente dentro desta pasta:

~~~sh
git init
git add .
git commit -m "Adiciona projeto inicial"
~~~

Nenhum repositório remoto é necessário para executar o projeto.
